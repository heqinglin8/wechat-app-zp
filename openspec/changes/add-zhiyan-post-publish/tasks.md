## 4. 发布流程与列表刷新

- [ ] 4.1 未登录用户进入或提交时提示登录，并禁止创建帖子。
- [ ] 4.2 正文为空时点击发布必须提示填写正文，并不得提交。
- [ ] 4.3 存在图片上传中时点击发布必须提示等待上传完成，并不得提交。
- [ ] 4.4 发布中防重复提交，发布按钮展示提交中状态。
- [ ] 4.5 发布成功后提示成功，并返回上一页。
- [ ] 4.6 发布成功返回职言列表后触发 `pages/zhiyan/zhiyan` 刷新，使新帖子可展示。
- [ ] 4.7 发布失败时保留标题、正文和已上传图片，并提示失败。
- [ ] 4.8 点击关闭时，如果存在标题、正文或图片，必须确认放弃；无内容时直接返回。
